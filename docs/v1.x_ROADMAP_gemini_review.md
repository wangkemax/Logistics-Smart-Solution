# 中长期 Roadmap 规划 (v1.1 - v1.4)
## Gemini Architecture Review (2026-04-02)

---

## 核心规划逻辑

**先筑牢物理与商业底座，再完善输入输出体验。坚决避免在没有"骨架"的地方堆砌 LLM 的"血肉"。**

## 详细规划

### v1.1 — Equipment & Physics（物理底座）

**核心功能：**
1. **Equipment Database** — 标准化设备库（AMR/ASRS/Shuttle/Conveyor/Sorter）参数定义
2. **Scenario-Equipment DI** — 场景引擎与设备库通过依赖注入解耦，支持基于吞吐量计算设备数量

**动机：** 解决 LLM 方案生成的"幻觉"和"空泛"问题。物流仓储的核心是设备，没有具体设备参数，方案就没有说服力。

**架构奠基：** 为 v1.2 的成本测算（Capex）提供精确底层数据源；彻底分离静态事实库与动态业务逻辑。

**退出标准：** `scenario_engine` 能通过查库返回具体的设备型号与测算数量；LLM 生成的文本中 100% 精确引用了设备库参数。

---

### v1.2 — Commercials & ROI（商业定价引擎）

**核心功能：**
1. **Financial Modeler** — 综合设备 Capex、人员 Opex、场地租赁等生成成本基线
2. **ROI / Payback Calculator** — 生成多周期现金流量表和投资回报期测算

**动机：** 这是售前的灵魂。客户看方案，最终看的是价格和回报。有了这个模块，系统才从"文档辅助工具"跃升为"业务决策系统"。

**架构奠基：** 将单纯的文本生成拓展到数学计算领域，确立 Cost Model 成为架构中的一等公民，与 Solution 平级。

**退出标准：** 输入一个假设组合，能自动化输出一份包含折旧、ROI 和成本拆解的 JSON/CSV 表格，且数值逻辑严密无误。

**真正的 MVP：** Gemini 判断 v1.2 才是"完整售前推进系统"的真正 MVP——系统才能端到端吐出"技术方案 + 商业报价 + ROI 分析"。

---

### v1.3 — RFP Ingestion（逆向解析引擎）

**核心功能：**
1. **Constraint Extractor** — 上传 RFP/招标文件，利用 LLM 提取关键约束（面积、SKU数、SLA要求等）
2. **Clarification Generator** — 对比 RFP 提取内容与 Assumption Defaults，自动生成"缺失信息澄清清单"

**动机：** 目前系统是从"假设"开始顺向生成的。真实的售前往往是从"阅读厚重招标文件"开始的。这补齐了系统的最前端输入。

**架构奠基：** 完善 Understanding Engine → Clarification 链路；建立非结构化文档到结构化 Assumption 的转换管道。

**退出标准：** 上传一份 20 页的 RFP，系统能自动填充至少 50% 的核心 Assumption，并列出 5 个需要向客户澄清的核心问题。

---

### v1.4 — Pitch & Presentation（决胜展示端）

**核心功能：**
1. **Markdown to PPT** — 基于结构化内容生成可渲染的演示大纲（Docs as Code 方案：Marp）
2. **Bid Scenario Diffing** — A/B 两个方案版本的参数与成本差异对比面板

**动机：** 当底层逻辑和商业测算都稳固后，优化"最后一公里"的交付体验。

**架构奠基：** 确立系统多方案并行管理的能力，丰富展现层的多模态输出。

**退出标准：** 系统能基于现有 Proposal 导出结构清晰的 Markdown 幻灯片代码，并能正确展示两个快照版本的成本差异图表。

## 依赖关系分析

### 必须串行（Critical Path）

```
Equipment Database (v1.1)
    ↓
Financial Modeler (v1.2)
    ↓
Bid Scenario Diffing (v1.4)
```

**理由：** 没有设备成本和数量，就无法算总账；没有总账，做版本差异对比毫无意义。

### 可以并行

**RFP Ingestion (v1.3)** 是系统最前端的输入，独立于后端的生成与计算逻辑。如果 Sprint 精力有富余，可以与 v1.1/v1.2 并行开发。

**UI 层完善**（Streamlit 面板迭代）应始终贯穿并伴随每个版本并行发布。

## 镀金功能警告（不应该做的）

| 镀金功能 | 替代方案 |
|---------|---------|
| python-pptx 高级排版（80%精力消耗） | 坚持导出 Markdown/纯文本，排版留给人类 |
| 3D 布局生成 / CAD 绘图自动化 | AI 生成面积/通道/分区文字指导，图纸由人工绘制 |
| 过度复杂的通用 RFP 解析 | 提取核心参数，置信度低的项交 Human-in-the-loop 确认 |

---

## 关键战略决策

**真正的 MVP 是 v1.2（Commercials & ROI）**。v1.0 是"Solution Generator MVP"，但没有精准成本测算和商业回报承诺，系统只能叫"技术白皮书"，不能叫"投标方案"。
